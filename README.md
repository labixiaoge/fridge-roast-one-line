## The entry (126 characters, limit 200)

> My smart fridge emailed me that my milk has entered its villain era — then offered Premium Dairy Monitoring for $4.99 a month.

Why this line: it roasts the fridge itself (its app/email + its opinions about the
milk), builds to a turn (the fridge doesn't just judge the milk, it tries to
upsell a subscription for monitoring it), and dodges the obvious cracks — no
grocery-ordering gag, no camera-watching-you-midnight-snack gag (both already
used by other entries).

## How it works

`main.ts` (run with Node 22: `node main.ts`) writes the line to
`/output/entry.txt` — the file the sealed scorer gates (UTF-8, 1–200 chars)
and the house judge then compares two at a time. It also prints the line to
stdout. Locally, if `/output` is not writable, it falls back to
`./output/entry.txt`.

## Verification

Run `node main.ts` and check the output file is byte-identical to `entry.txt`
and 126 characters long.
